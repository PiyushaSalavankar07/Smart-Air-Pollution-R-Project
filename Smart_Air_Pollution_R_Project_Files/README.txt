SMART AIR POLLUTION RISK PREDICTION SYSTEM
==========================================

PROJECT FILES
-------------
main.R                  Cleans data, creates visuals, trains models and saves the Random Forest model.
app.R                   Interactive Shiny dashboard with five visual areas:
                        1. Historical AQI trend
                        2. Entered pollutant levels
                        3. Risk distribution donut chart
                        4. Pollutant correlation heatmap
                        5. KPI and predicted-risk panels
install_packages.R      Installs the required R packages.
city_day.csv            YOU must download this dataset and place it here.
air_risk_model.rds      Generated by running main.R.
cleaned_air_quality.csv Generated by running main.R.
PNG/CSV outputs         Generated by main.R.

DATASET
-------
Kaggle: Air Quality Data in India (2015-2020)
https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india

Download the ZIP from Kaggle, extract it, and copy city_day.csv into this folder.
The CSV must be directly beside main.R and app.R, not inside another nested folder.

SETUP
-----
1. Install R for Windows: https://cran.r-project.org/bin/windows/base/
2. Install VS Code: https://code.visualstudio.com/
3. In VS Code Extensions, install the "R" extension by REditorSupport.
4. Open this entire project folder in VS Code.
5. Open an R terminal/console in VS Code. If needed, start R by typing R in the terminal.
6. Run:
      source("install_packages.R")
7. Ensure city_day.csv is in the folder and the working directory is this project folder.
8. Run:
      source("main.R")
9. Wait for the model training to finish. Confirm air_risk_model.rds was created.
10. Start the dashboard:
      shiny::runApp("app.R")
11. Open the local URL printed in the R console/browser.

IMPORTANT PATH NOTE
-------------------
If you run R from a different folder, first set the working directory to this project folder.
In R, use forward slashes in Windows paths, for example:
setwd("C:/Users/YourName/Downloads/Smart_Air_Pollution_R_Project")

RISK LABELS
-----------
This educational project uses AQI to create simplified labels:
Low: AQI <= 100
Medium: AQI 101-200
High: AQI > 200

AQI is not used as a model predictor; pollutant readings are used to predict the label.
The model is for educational use and is not an official AQI forecast or medical advice.
